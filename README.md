Practice Problem 1: Personal Information & Simple Calculator
Task:
Create a Python program named personal_calculator.py that performs the following tasks:
1. Ask the user for their name.
2. Ask for their age.
3. Ask for two numbers.
4. Calculate the sum, subtraction, multiplication, and division of those two numbers.
5. Display all information in a well-formatted output using f-strings.
Expected Output Example:
Enter your name: Rahim
Enter your age: 22
Enter first number: 20
Enter second number: 10
Hello, Rahim!
Your age is 22.
Addition: 30
Subtraction: 10
Multiplication: 200
Division: 2.0
Practice Problem 2: Student Grade Calculator
Task:
Create a Python program named grade_calculator.py that:
1. Takes a student's name as input.
2. Takes marks for three subjects.
3. Calculates the average marks.
4. Determines the grade using the following conditions:
Average Marks Grade
80–100 A+
70–79 A
60–69 A50–59 B
40–49 C
Below 40 F
5. Display the student's name, average marks, and final grade.
6. If any subject mark is below 0 or above 100, display an invalid marks message.
Expected Output Example:
Enter student name: Rahim
Enter Math marks: 85
Enter English marks: 75
Enter Python marks: 90
Student Name: Rahim
Average Marks: 83.33
Final Grade: A+
